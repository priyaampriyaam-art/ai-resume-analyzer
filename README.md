# AI Resume Analyzer - UNLOX Project

This is my AI project for UNLOX AI Internship.

**Problem:** Many MBA and BCom students dont know which job is best for their resume.

**What my project does:**
- Upload Resume PDF
- My code reads resume and finds skills
- It matches resume with 5 jobs like Finance Analyst, Business Analyst, Accountant
- Shows bar chart and tells which job is best match
- Also tells missing skills to learn

**Technology Used:**
- Python
- Streamlit for website
- scikit-learn (TF-IDF and Cosine Similarity)
- pypdf for reading PDF
